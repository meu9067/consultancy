Accessibility Statement

Last updated: 16 November 2026.

{{name}} is committed to making this website accessible, in line with the standards {{name}} helps other organisations meet. This statement describes the conformance target, how conformance was tested, and what to do if you run into a problem.

Conformance target

This site targets WCAG 2.2 Level AA, the standard referenced by the European Accessibility Act and EN 301 549.

How this was tested

Both automated and manual testing were used, because automated tools alone only catch a fraction of real accessibility issues:

  • Automated scanning with axe-core and HTML_CodeSniffer (via Pa11y), across the dark theme, the light theme, and the mobile navigation menu.
  • Lighthouse accessibility audits.
  • HTML markup validation.
  • A dedicated colour-contrast audit computed directly from the site's theme colours for every foreground/background pairing, in both themes.
  • A keyboard-only and real-interaction test: tabbing through every control, confirming focus order and visibility, and simulating actual clicks and key presses rather than only inspecting markup.

These checks run automatically before every deployment.

Known limitations

  • The decorative night-sky background image is marked aria-hidden and purely visual, but as with any photographic background, it has not been independently tested by assistive-technology users in every combination of device and screen reader.
  • Automated testing cannot fully verify screen reader announcement quality in every browser/AT combination; this is reviewed periodically but not on every single change.
