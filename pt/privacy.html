Política de Privacidade

Última atualização: 16 de novembro de 2026.

Este é um site estático, de página única. Não utiliza cookies, não executa scripts de análise ou publicidade de terceiros, e não recolhe dados pessoais através de nenhum formulário neste site — não existe nenhum. Esta política explica a pequena quantidade de dados que é processada e porquê.

Que dados são processados

  • Preferência de tema. Se utilizar o botão de alternância entre modo claro/escuro, a sua escolha é guardada no localStorage do seu navegador, para ser recordada na próxima visita. Esta informação nunca sai do seu dispositivo e não é enviada para nenhum servidor.
  • Registos de servidor padrão. Como praticamente todo o alojamento web, o servidor/CDN que serve este site pode registar dados técnicos básicos do pedido (endereço IP, user agent, URL pedido, data/hora) para fins de segurança e operacionais. Estes registos não são utilizados para rastreio ou criação de perfis.
  • Google Fonts. Este site carrega o tipo de letra "Atkinson Hyperlegible" a partir do fonts.googleapis.com/fonts.gstatic.com da Google. Carregar um tipo de letra a partir dos servidores da Google significa que o seu navegador faz um pedido à Google, que pode processar os dados técnicos associados ao pedido (como o seu endereço IP) de acordo com a sua própria política de privacidade.
  • Dados de contacto que opte por enviar. Se enviar um email ou uma mensagem via LinkedIn/GitHub através das ligações neste site, o que enviar é processado da mesma forma que qualquer email ou mensagem direta — não é recolhido por este site.

Os seus direitos

Se estiver na UE/EEE, tem direitos ao abrigo do RGPD (acesso, retificação, eliminação, oposição) sobre quaisquer dados pessoais processados em relação a este site. Dada a reduzida quantidade de dados processados, isto diz essencialmente respeito aos registos de servidor e aos pedidos à Google Fonts descritos acima. Para colocar uma questão ou exercer um direito, contacte {{name}} através de {{email}}.

Alterações a esta política

Se o que este site recolhe ou a forma como é alojado mudar, esta página será atualizada e a data de "última atualização" acima será alterada em conformidade.
